# Family Tree Generator – verze 0.1

## Spuštění
1. Rozbal ZIP archiv.
2. Otevři složku `family-tree-generator`.
3. Otevři `index.html` v prohlížeči.

Není potřeba instalovat Node.js, server ani další knihovny.

## Soubory
- `index.html` – struktura stránky
- `style.css` – vzhled aplikace
- `script.js` – formulář, rozložení rodokmenu a export SVG

## Rozsah první verze
- 4 generace včetně výchozí osoby (15 osob)
- jméno a příjmení + profese
- vertikální a horizontální orientace
- automatické spojovací čáry
- export do SVG

## Poznámka
Google Fonts se načítají z internetu. Samotný generátor a jeho data fungují lokálně v prohlížeči.
